# Henloa

App privada de pareja (Henry & Loany) hecha con Flutter Web + Firestore.

- Lista de expectativas de cada uno + autoevaluación cruzada semanal (sábados), del 1 al 10.
- Progreso: promedio semanal, rangos e historial.
- Deseos y antojos.
- Buzón de cartas, con vista en PDF.

Acceso por código de 4 dígitos (sin cuentas). Publicado en GitHub Pages.
